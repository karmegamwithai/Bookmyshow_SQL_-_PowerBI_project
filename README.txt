BookMyShow Analytics Portfolio Website

Open index.html in a browser, or host the folder on GitHub Pages / Netlify / Vercel.

Files:
- index.html: project overview and BRD summary
- sql.html: SQL requirements and SQL download page
- powerbi.html: five dashboard screenshot previews
- bookmyshow_analysis.sql: 20 SQL analysis query templates
- style.css: shared red/black styling (Tailwind CDN is included in each page)
- assets/: supplied Power BI dashboard screenshots and BRD document

IMPORTANT:
The supplied BRD does not define all physical database column names. The SQL file
documents its assumed schema at the top; align names/status rules to your database.
A .pbix file was not supplied, so the Power BI page shows previews but no PBIX download.
